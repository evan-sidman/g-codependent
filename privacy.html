G-CODEPENDENT tools

Privacy policy

Last updated: 29 October 2026

G-CODEPENDENT tools ("the app") is a private publishing helper used only by the owner of the G-CODEPENDENT YouTube channel to manage that channel. It is not offered to the public.

Data the app accesses

When the channel owner signs in with Google and grants access, the app uses YouTube API Services to access:

  • the signed-in user's own channel and the list of its uploaded videos;
  • the metadata and settings of those videos (title, description, privacy status, scheduled publish time, audience setting);
  • YouTube Analytics reports for that channel.

The app does not access email, contacts, files or any other Google account data, and does not access other people's channels.

How the data is used

Only to set titles, descriptions, audience settings and publish times on the owner's own videos, and to read the channel's statistics for planning. The data is not used for advertising, is not sold and is not shared with anyone.

Storage

The app runs on the owner's own computer. The OAuth access and refresh tokens are stored only in a local file on that computer. Video metadata and analytics are processed locally and are not sent to any server other than Google's own APIs. There is no app server and no database.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. Deleting the local token file removes all data the app stores.
